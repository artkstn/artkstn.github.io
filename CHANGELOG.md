# CHANGELOG

Журнал значимых изменений проекта. Формат и правила ведения — в CLAUDE.md
(раздел «Ведение журналов изменений и ошибок»).

## [2026-09-22]
- Редактура текста резюме (модалка и PDF) по методу Сарычевой + взгляд рекрутера:
  убран голословный пункт без фактуры («Отвечал за UX B2B-продуктов…», Т-Банк), два
  «пункта-солянки» с двумя разными достижениями в одном предложении разбиты на
  отдельные (AIC, Ozon 2021–2022), у самого слабого пункта (фиксация UI-дефектов)
  расплывчатая формулировка заменена на конкретную
- По всему тексту страницы, модалки и PDF расставлены неразрывные пробелы: короткие
  предлоги/союзы, тире (чтобы не начинало строку), число + единица/существительное,
  разделители «·» в контактах — иначе типографика «плыла» на переносах строк
- Кнопка «Скачать PDF» в модалке резюме закреплена футером и видна при любой прокрутке —
  не нужно скроллить весь текст, чтобы её найти
- Кнопка «CV» в hero-секции теперь открывает модальное окно с текстовой версией резюме
  на русском языке вместо перехода на внешнюю страницу (Notion). Резюме — только опыт
  и «о себе» (без образования и навыков), закрытие — крестиком в углу страницы (Esc,
  клик по подложке тоже работают)
- В модалке — кнопка «Скачать PDF», ссылающаяся на `files/Artem-Kostin-CV-RU.pdf`:
  резюме, свёрстанное в стиле сайта (Golos Text, токены цветов) и сгенерированное из
  HTML через headless Chromium; приоритет — читаемость, а не объём в одну страницу
- Появилась папка `files/` под скачиваемые документы

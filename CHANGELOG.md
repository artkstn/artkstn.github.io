# CHANGELOG

Журнал значимых изменений проекта. Формат и правила ведения — в CLAUDE.md
(раздел «Ведение журналов изменений и ошибок»).

## [2026-09-23] (2)
- Правки шаблона страницы кейса по фидбеку: заголовок кейса разбит на короткий h1 и
  подзаголовок помельче (было слишком крупное сплошное предложение), из мета-блока
  убрано поле «Роль» (пока лишнее), у карточек убраны годы (`.card__tag` с датами) —
  тег остался только для «Скоро». Блок «Следующий кейс» стал компактной горизонтальной
  карточкой (превью-миниатюра + название) вместо полноразмерной .card на весь экран.
  Внизу каждой страницы кейса добавлен блок Telegram/CV/LinkedIn — на кейсах кнопка CV
  сразу скачивает PDF (без модалки с текстом резюме, как на главной, — дублировать
  модалку в script.js ради этого не стали)

## [2026-09-23]
- Смена архитектуры: сайт стал многостраничным. Появились `cases/` (шаблон страницы
  кейса), `styles.css` и `script.js` — общие для страниц кейсов (тема, появление блоков
  при прокрутке, токены и стили карточек), чтобы не дублировать вёрстку в каждом файле
  кейса. `index.html` остался самодостаточным файлом со своими инлайн-стилями/скриптом
  по прежней конвенции — общие блоки в `styles.css`/`script.js` продублированы, а не
  вынесены из index.html, синхронизировать токены нужно в обоих местах
- Карточки проектов на главной теперь бывают активными (ссылка на страницу в `cases/`)
  и неактивными («Скоро» — кейс ещё не описан). Сейчас неактивен только Betest — по
  нему пока нет содержимого; остальные три ведут на реальные страницы кейсов
- Добавлены страницы трёх кейсов (`cases/route-planner-cs.html`,
  `cases/ozon-point.html`, `cases/arrival.html`) по мотивам прежнего сайта
  akostin.framer.website — текст черновой, взят из фактов резюме на главной странице,
  ожидает переписывания; картинки — плейсхолдеры (`.card__ph`). На каждой странице —
  переход на главную и на следующий кейс (по кругу)

## [2026-09-22]
- Крестик закрытия модалки резюме: текстовый глиф заменён на SVG (был визуально
  нецентрирован в разных браузерах), позиционирование — `absolute` внутри карточки
  вместо `fixed` к вьюпорту (на iOS Safari дёргался при скролле из-за анимации
  адресной строки, см. MISTAKES.md)
- Клик по email в контактах модалки резюме копирует адрес в буфер обмена вместо
  перехода в почтовый клиент; над ссылкой появляется подсказка «Скопировано», плюс
  отдельное объявление для скринридеров. Cmd/Ctrl/Shift-клик по-прежнему открывает
  mailto: как обычная ссылка
- Редактура текста резюме (модалка и PDF) по методу Сарычевой + взгляд рекрутера:
  убран голословный пункт без фактуры («Отвечал за UX B2B-продуктов…», Т-Банк), два
  «пункта-солянки» с двумя разными достижениями в одном предложении разбиты на
  отдельные (AIC, Ozon 2021–2022), у самого слабого пункта (фиксация UI-дефектов)
  расплывчатая формулировка заменена на конкретную
- По всему тексту страницы, модалки и PDF расставлены неразрывные пробелы: короткие
  предлоги/союзы, тире (чтобы не начинало строку), число + единица/существительное,
  разделители «·» в контактах — иначе типографика «плыла» на переносах строк
- Кнопка «Скачать PDF» в модалке резюме закреплена футером и видна при любой прокрутке —
  не нужно скроллить весь текст, чтобы её найти
- Кнопка «CV» в hero-секции теперь открывает модальное окно с текстовой версией резюме
  на русском языке вместо перехода на внешнюю страницу (Notion). Резюме — только опыт
  и «о себе» (без образования и навыков), закрытие — крестиком в углу страницы (Esc,
  клик по подложке тоже работают)
- В модалке — кнопка «Скачать PDF», ссылающаяся на `files/Artem-Kostin-CV-RU.pdf`:
  резюме, свёрстанное в стиле сайта (Golos Text, токены цветов) и сгенерированное из
  HTML через headless Chromium; приоритет — читаемость, а не объём в одну страницу
- Появилась папка `files/` под скачиваемые документы
